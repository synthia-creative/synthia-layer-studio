# 統合制作ツール（v1.6.0）

WindowsのChrome / Edgeを推奨します。左側の「統合制作ツール」→「拡張のオン／オフ」で必要な機能を選び、その機能欄を開きます。すべて初期状態はOFFです。設定はプロジェクトJSONの追加項目 `studio` に保存され、旧version 1の歌詞・演出・時刻は維持します。従来のタイムライン、モーションライブラリ、字幕ペア／フロントMP4、完成MP4も引き続き使えます。

## 歌詞から制作する

1. 音源を読み込みます。歌詞は従来の欄、SRT、LRC、または「歌詞・タイミング」で貼り付けます。空行は区切りか「[間奏]」として選択できます。
2. SRTの開始・終了はそのまま使います。通常歌詞はTap Syncでタイミングを付けます。「現在の歌詞を字幕時刻編集へ」は明示操作で現在のプランを字幕にします。
3. 演出を作り、必要に応じ文字・レイヤーを調整します。JSONを保存し、完成MP4を出力します。音源・画像・動画はJSONに含まれないため、次回は再読込します。

## Tap Sync

「Tap Sync拡張」をONにし、従来のTap開始ボタンで再生を開始します。現在／次の歌詞、進捗、時刻を見ながらSpaceまたは大きなTapボタンを押します。マウス・タッチ・ペンのpointer入力に対応します。Undoボタン／Backspaceで最後の入力を戻せます。最終行を押した後でも戻して再入力できます。終了余白は0 / 50 / 100 / 150msです。

入力欄、設定ダイアログ、ボタン操作、ドラッグ中のSpaceをTapとして扱いません。SRTを読み込んでいる場合はその確定時刻を保持します。通常の曲再生ではSpaceの従来操作を維持します。

## 文字・書体・モーション

- 「文字単位編集」のLine / Characterを選び、プレビュー上の文字を選択・ドラッグします。座標、拡大率、回転、不透明度、字間を調整できます。絵文字はコードポイント単位、改行は文字番号から除外します。結合文字や複雑な字形はフォントによって別々に扱われる場合があります。
- 「フォントファイル」でTTF / OTF / WOFF / WOFF2を選ぶかドロップします。1ファイル8MB以下、最大8個、base64合計24MB以下。フォントをJSON・IndexedDBに含めて復元します。配布するJSONにはフォントの利用・再配布条件を確認してください。従来のPC書体一覧／書体名入力も使用できます。
- 「段階別モーション」でIN / HOLD / OUT、強度0〜1、感覚コントロール0〜100を設定します。10種類のプリセットは既存のモーション機構を組み合わせます。拡張をOFFにすると従来の演出に戻ります。

## Auto

従来の「おまかせ」はDesign Autoとして引き続き使えます。「楽曲解析」で音源のRMS / Peak / Energy / Onset / Beat推定・区間変化・文字密度を確認します。同じ音源の解析はキャッシュします。区間は `開始秒, 終了秒, Intro/Verse/PreChorus/Chorus/Bridge/Outro` の形式で手動指定できます。区間変化の自動検出はVerse/Chorusの意味を判定するものではありません。

Music Autoは音量・密度・区間から演出を選びます。Full Autoは既存のおまかせとMusic Autoを組み合わせます。SRTの開始・終了は変更しません。Beat Snapは初期OFFで、20 / 50 / 100 / 150msを選んで明示的に適用した場合だけ、その範囲内の開始時刻を近い拍へ寄せ、字幕の長さを維持します。SRTの確定時刻を優先する場合はOFFのまま使用してください。

## タイムライン・レイヤー

従来のタイムラインの下に補助トラックを追加します。字幕ブロックをドラッグして移動し、右端で長さを調整します。選択字幕の複製・削除も可能です。通常歌詞を初めてブロック編集する場合は、現在の時刻を明示字幕として保持します。

Lyrics / Text / Image / Video / Overlay / Effect / Backgroundを合成します。下のレイヤーから上へ描画し、選択レイヤーの移動、削除、表示範囲、ブレンド、不透明度、座標、拡大、回転を調整できます。Lyricsレイヤーは保持します。Image / Videoはレイヤーを選んで素材を読み込みます。動画は開始位置以降に再生し、終了後は最後のフレームを保持します。追加トラックは補助表示で、波形のサンプル編集や映像クリップのトリミング用NLEではありません。

## Export

「追加書き出し」でファイル名を指定して「完成MP4」を選びます。既存の簡易動画設定で解像度・長さを設定できます。従来のH.264 / AACエンジンに歌詞、字別調整、追加画像／動画／テキストを合成します。読み込まれていない有効な追加画像／動画がある場合は、再読込を求めて出力を止めます。

「透過歌詞PNG連番ZIP」は歌詞とその既存装飾を透過PNGで出力します。追加の背景／画像／動画／テキストは含みません。最大18,000フレームで、メモリが不足する場合は短い範囲・低い解像度で分割してください。キャンセルできます。WebM、アルファ付き動画は今回追加していません。

## 保存・復元と制約

「自動保存・復元」をONにすると編集後・15秒ごと・完成MP4／PNG出力前にIndexedDBへ保存します。次回起動時に復元か破棄を選びます。「今すぐ自動保存」で保存済み表示を確認してから閉じてください。拡張OFFで復元データを削除します。破棄は空プロジェクトから開始します。音源・画像・動画は再読込します。

大量のフォントを含む設定は従来localStorageの容量を超える場合があります。IndexedDB自動保存をONにし、JSONも保存してください。ブラウザデータ削除、プライベートモード、容量制限、別ブラウザ／別オリジンへの移動では保存を共有・保証できません。物理ペン、実機スマホ、Mac Safari、長時間4K素材は別途確認が必要です。
