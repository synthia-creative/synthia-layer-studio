映像自動解析 — Video Analysis Engine v1.0

この機能は、背景動画・静止画から人物や動きなどを推定して、字幕の配置を検討するための補助機能です。従来の編集・描画・MP4出力エンジンを使い続けます。文字モーションの自動生成や動画自動編集は行いません。

最初の操作

  1. HTTPでアプリを開き、作業用背景に動画または静止画を読み込みます。
  2. 「統合制作ツール」→「映像自動解析」を開きます。字幕がなくても解析できます。
  3. 「映像自動解析 ON / OFF」をONにし、品質・開始秒・終了秒・検出項目を選び、「解析開始」を押します。ONだけでは処理は始まりません。
  4. 完了後、「解析結果の表示 ON / OFF」をONにします。顔・人物領域・動き・明暗・シーン候補を確認できます。
  5. 字幕がある場合は「Safe Zone候補と字幕位置」で対象字幕を選び、「配置候補を計算」します。最大3候補の点数・衝突リスク・視認性・解析信頼度を比較します。
  6. 候補をプレビューし、人物や文字の動きを目視で確認してから「選択字幕にこの位置を適用」を押します。位置以外の書体・配色・時刻・モーションは保持します。Ctrl+Zで取り消せます。
解析表示動作
OFFOFF新しい解析はできず、ガイドも隠れます。通常の編集を継続できます。
ONOFF「解析開始」で処理します。結果のガイドは隠れています。
OFFON保存済みで素材と一致する結果を表示できます。新しい解析は始まりません。
ONON「解析開始」で処理し、完了後の結果を表示できます。

起動・プロジェクト読込・解析JSON読込時は両スイッチがOFFです。両スイッチはプロジェクトやブラウザに保存しません。解析OFFにすると処理途中のWorker・デコードを中止します。以前の解析結果・手動保護領域・適用済み位置は残り、表示スイッチは変えません。「解析キャンセル」も使えます。素材の変更は処理を中止し、一致確認が終わるまでガイドを隠します。書き出し開始時も進行中の解析を中止して出力を優先します。

品質・範囲・処理量

サイズは縮小フレームの長辺の上限です。元の動画解像度は変更しません。

品質動き・明暗顔・人物通常のサンプル間隔顔・人物の頻度
高速160px320px約1秒3サンプルに1回＋末尾
標準240px512px約0.5秒2サンプルに1回＋末尾
高精度320px640px約0.25秒毎回

標準・高精度では、全体の検出に加えて6個の重なり合う領域でも顔を検出し、重複を除きます。高精度はカット候補の前後にサンプルを追加して、時系列で再評価します。

開始秒・終了秒で素材内の範囲を指定します。終了秒0は末尾まで。フレーム数は既定600、最大1200です。上限を超える長さでは間隔を広げ、FRAME_CAP警告を表示します。字幕区間のカバー不足や大きな間隔がある候補は暫定評価です。全フレームや元解像度のマスクを保存せず、縮小フレーム1枚ずつ処理します。端末や素材によって所要時間は変わります。

推定方法と読み方

  • 動き：縮小グレースケールの疎なブロック照合。移動量を秒・画面サイズで正規化し、領域別強度と全体の中央値方向を保存します。テクスチャのない領域は信頼度を下げます。カット・強い明暗変化は通常の移動として扱いません。
  • シーン：色差ヒストグラム、輝度差、エッジ量を組み合わせたカット候補です。明暗だけの変化はフラッシュ・フェード候補として分けます。判定は厳密な映像編集境界の復元ではありません。
  • 明暗：平均・最小・最大輝度、コントラスト、RGB平均、8×6領域の明暗・複雑度です。
  • 顔：MediaPipe BlazeFace short-range float16 v1。矩形・モデルスコアを保存し、短い時間の対応付けを行います。見失った顔は最大1秒の推定保護に使います。顔の保護余白を設定できます。
  • 人物：MediaPipe SelfieSegmenter float16 v1。人物の前景信頼度から16×9の占有率と外接矩形を作ります。固定モデルの出力は1チャネルのsigmoid前景です。別モデルのカテゴリ番号を無条件に人物とみなしません。
  • Safe Zone：各字幕区間で、既存描画器から文字の回転・拡大・モーションを含む範囲を有限サンプリングで測定します。人物・顔・保護領域・他字幕・背景複雑度・動き・色のコントラスト・画面端を評価し、最大3候補を並べます。

配置スコアはモデル確率ではありません。基本の重みは顔45%、人物22%、複雑度10%、視認性10%、動き8%、画面端5%。手動保護領域・他字幕との重なりは強く減点します。スコア、顔・人物衝突リスク、視認性、解析信頼度を別々に表示します。信頼度はモデル利用状態・時間カバー・検出の不確実性を加味した推定指標です。検出がゼロでも、人がいない証明にはなりません。

推奨色は参考表示のみです。Safe Zoneの色・位置・モーションは自動で上書きしません。安全な候補がない場合は暫定候補として表示し、適用時に確認します。

手動保護と位置調整

「手動保護領域」から、素材内のX/Y/幅/高さの割合と開始・終了秒を指定します。追加・更新・削除に対応します。プレビュー操作を「ドラッグで新規領域」「移動」「右下を変更」に切り替えて調整することもできます。領域は素材のハッシュと時間に結び付けます。人物が大きく移動する場合は時間ごとに領域を追加します。自動検出が失敗しても利用できます。再解析で手動領域は消えません。

手動字幕位置は、測定した文字範囲の中心をX/Yの指定位置へ移動します。「位置上書きを解除」で従来の配置へ戻せます。ロック字幕への候補適用・手動適用・解除は拒否します。

複数字幕へ適用する場合は、対象を選択して候補を計算し、各行のプレビューを確認します。全対象をプレビューした後にだけ一括適用できます。全字幕の選択にも対応します。確認ダイアログの後に位置だけをまとめて適用し、1回のCtrl+Zで戻せます。

ガイドはプレビューの別Canvasです。フロント／マット／簡易完成MP4・範囲出力・透過PNGには入りません。未適用の候補プレビューも出力には入りません。適用済み位置は通常の描画器へ渡すため、解析OFF・ガイドOFFでもプレビューと出力に反映されます。

保存と再開

「解析結果を保存」で素材名.analysis.jsonを保存します。プロジェクトJSONにも任意データvideoAnalysisとして結果・設定・領域・位置を含みます。従来のversion 1プロジェクトは解析項目がなくても読み込めます。解析項目が壊れている場合は解析だけを無効にし、通常の編集を継続します。

再開時は背景素材を選び直してください。ファイルサイズ・寸法・種類・動画時間・SHA-256が一致する結果だけを表示します。ファイル名の一致だけでは採用しません。12MiB以下はファイル全体、それより大きい場合は先頭・中央・末尾の各1MiBとサイズからハッシュを計算します。後者は完全なファイル同一性の証明ではありません。JSONにhashModeを保存します。解析JSONの読込上限は16MiBです。読み込みで既存の位置を自動適用・上書きしません。

「解析結果の削除」は解析結果だけを消し、手動保護領域と位置は保持します。プロジェクト初期化は従来どおり現在のプロジェクトを初期化します。

起動と静的配布

PCのChrome/Edgeで、フォルダ内から次を実行します。Pythonが使える環境では追加パッケージは不要です。

python -m http.server 8765 --bind 127.0.0.1

http://127.0.0.1:8765/が日本語、/en/が英語です。HTTPサーバーは静的ファイルを配るだけで、素材を送信する処理はありません。ネット接続なしでも、同梱の解析モデルを利用できます。既存のGoogle Fontsは別途外部取得する場合があります。

本体は従来どおりビルド済みHTMLです。人物解析はブラウザのES Module/WASM読込制約によりfile://から利用できません。直接HTMLを開いた場合も通常編集は使えます。静的公開時はHTMLとvendor/vision/の階層を一緒に配置し、.mjsをJavaScript、.wasmをapplication/wasmで配信してください。ルート・サブディレクトリ・英語版からの相対パスに対応します。厳しいCSPではblob Worker・同一オリジンのモデル取得を許可する必要があります。公開操作は別途行います。

既知の制限

  • 推定結果の目視確認が必要です。横顔・遮蔽・遠い／小さい顔・暗所・アニメやAIキャラクターは検出漏れや誤検出があります。人物モデルは主に大きく映る人物向けで、サイズの違う複数人物をすべて保護する保証はありません。
  • 8×6／16×9の粗い領域と間引いた時間を使います。細い指や髪、短い出現、急速な移動は漏れる場合があります。顔IDは簡単な幾何対応で、人物識別は行いません。
  • 動きは局所探索の近似です。カメラパンと人物移動の完全な分離、長い移動やサブピクセルの精密計測は未対応です。カットと似た色の変化や短いフラッシュには限界があります。
  • 字幕測定は480px・約8fps・基本最大160点とカット境界です。全フレーム／全画素の最適配置の証明ではありません。特殊な後処理や画面外・クリップ領域は保守的な範囲になることがあります。
  • 背景は既存仕様の開始0秒・速度1・ループなし・末尾保持です。別の再生オフセット／速度設定は未追加です。動画fpsは正確に取得できないためJSONではnullです。
  • コーデックはブラウザがデコードできるものに限ります。破損・非対応時は警告して解析を終了します。MP4出力は既存WebCodecs環境に依存します。
  • Worker非対応／WASM読込失敗では人物解析が利用できません。モデル失敗時は基礎解析を続け、Safe Zoneを暫定評価にします。通常編集は継続できます。
  • 長時間や4Kの元素材を解析すると、動画デコーダ自身のメモリ消費も増えます。全プロセスのピークメモリ上限は保証しません。

拡張用データ

J.VideoAnalysis.run(media, options, signal, onProgress)が検証済み結果を返します。evaluateSafeAsync(result, regions, interval, envelope, luminance, others, signal)が候補を返します。source、range、mapping、samples[t]のmotion/brightness/faces/person/change、scenes、safeZonesを将来の演出提案へ接続できます。videoAnalysis.placements[cue-ID/line-index]は字幕位置の明示適用データで、文字本文も照合します。自動モーション生成へ接続する実装は今回含めていません。

固定モデル・ライセンス・一次資料

MediaPipe Tasks Visionは0.10.21、モデルはそれぞれfloat16のバージョン1です。配布元・サイズ・SHA-256はvendor/vision/manifest.json、ライセンスはvendor/vision/LICENSE.txtと第三者表記に記載しています。OpenCV.jsの大型ランタイムを増やさず、基礎計測をJavaScript Workerで実装しました。顔・人物だけに固定MediaPipeモデルを使います。

候補が要確認になる場合（v1.7.1）

候補ごとに具体的な理由と対処を表示します。文字の出入りを1個の巨大な範囲にまとめず、約8fpsの各時刻で描画範囲・人物・同時表示の別字幕を評価します。候補の矩形と手動位置の中心は字幕区間の中央付近の描画範囲です。実際に顔・人物・保護領域へ重なる場合は要確認のままです。文字を小さくする、モーションを変える、推奨色を確認するなど、表示理由に合わせて調整してください。

長い動画の別の区間に大きな解析間隔があっても、対象字幕の区間が十分に解析されていれば範囲不足とは扱いません。書体の縁取り・グラデーション・影の見やすさは単色近似で、目視確認してください。
