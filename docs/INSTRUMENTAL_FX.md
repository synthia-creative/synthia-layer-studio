# 間奏演出 / Instrumental FX Engine v2.0

## v2.0 音楽連動演出（開発版）

1. SRTと音源を読み込み、「曲の雰囲気」と「演出の強さ」を選びます。初期値で使えます。
2. EQ・波形・映像エフェクトの表示を選び、「音楽連動エフェクトを自動作成」を1回押します。
3. 区間検出、必要な音声解析、生成、親機能・Auto・プレビューONをまとめて行います。ManualのON/OFFは変えません。

曲調はバラード／ロック／EDM／ポップ／シネマティック／Lo-Fi。組み合わせ、色、帯域、反応速度、発光、ビート反応を曲調に合わせて設定し、通常は区間あたり最大3個に抑えます。EQ・波形・映像のOFFは保存データを削除しません。親機能・Auto・Manualの初期OFFと保存状態を維持します。

### 新しい音楽描画

- **Audio Spectrum**：横型EQ、上下対称EQ、円形。低／中／高域、8〜64バー、色、感度、滑らかさ、発光を調整できます。low品質では最大24バーです。
- **Audio Waveform**：実際の音声サンプルから滑らかな直線／円形の波形を描きます。高さ、線幅、色、発光、音の立ち上がりによる揺れを調整できます。
- **Audio Reactive Transform**：図形、既存FX、追加レイヤーの画像などに、音量による拡大・透明度・発光と、実音声のOnsetに対応するビートによる回転・移動を割り当てます。対象の元データは変えません。発光FX自体の明度制限は維持します。画像は追加トラックをONにし、素材を読み込んでください。対象がなくなったときは別の対象へ移しません。

「詳細設定を開く」から手動追加、対象FX一覧、種類の差し替え、区間編集、タイムライン、プリセット、Undo/Redoを使えます。「音声特徴量を解析」はSRTがない場合の手動FX準備にも使えます。v1.1のかんたん個別操作は詳細モード内に維持しています。

### 音声解析と保存

既存の64バーFFTを共通キャッシュから再利用し、Music Autoと同じRMS・Peak・Onset・Beatを使います。低域20〜250Hz、中域250〜4000Hz、高域4000Hz〜Nyquistを測定します。波形は実音声の符号付きサンプルです。音楽反応を周期アニメーションで代用しません。

Attack、Release、スムージング、ピーク保持と帯域感度は詳細編集で調整できます。特徴量は事前計算し、時刻から補間するため、再生・途中シーク・完成MP4で同じ結果を使います。無音には音楽反応を作りません。音源が変わった場合は「自動作成」または詳細の解析で更新してください。

特徴量はJSON／自動保存に含まれます。5分までは30Hz、長い曲は最大9000フレームに収まるよう解析レートを下げます。実際のレートは詳細モードに表示します。音源・画像・動画の本体はJSONに含まれません。保存済みの実解析結果は音源未指定でも描画に使えますが、別の音源を読み込んだ場合は更新が必要です。

### 映像効果・品質・安全性

RGBグリッチ（色収差）、Glow、Motion Blur、Radial Blur、Light Rays、Zoom Pulse、Mirror、Kaleidoscope、Film Grainを追加しました。RMS／Peak／Onset／Beat／低中高域を発動条件にできます。背景・歌詞・レイヤー・FXを共通合成した後に処理します。前面の新しいEQ／波形は画像レイヤーにも隠れにくい順序で描きます。

重い映像効果は最大2個まで処理し、low／standard／highで作業キャンバスの長辺を480／960／1280px、ブラーの重ね回数を3／5／8に制限します。映像エフェクトON/OFFで停止できます。既定の安全制限とOSの動きを減らす設定を尊重します。

操作中に重い場合はlow品質を選び、完成出力前に必要な品質へ戻してください。作業画面内で映像処理を完結させてから合成しますが、高解像度の光線・ブラーは機器によって実時間再生より遅くなることがあります。品質を変えても音声特徴量・時刻・保存したFX設定は保持します。

Motion Blurは方向に沿った空間ブラーです。過去フレームを蓄積する時間ブラーは実装していません。Radial Blurは同じ時刻の画像の拡大サンプルを重ねます。この方式で途中シークと書き出しの再現性を保ちます。

旧FX・字幕・Music Auto・Video Analysis・64バー内蔵スペアナを維持します。映像解析は自動開始しません。完成MP4は新FXを含み、字幕専用フロント／マット・透過歌詞PNGは従来どおり除外します。公開サイトへの反映は別途公開作業が必要です。

## v1.1 かんたん個別操作（詳細モード内）

1. 「SRTを読み込む」で字幕を読み込み、音源を読み込みます。
2. 「間奏エフェクトを自動で追加」を1回押します。「おまかせ」「ふつう」のままで使えます。
3. 前奏・間奏・アウトロの検出、必要な楽曲解析、生成、親機能と自動表示のONまで行い、生成した間奏へプレビューを移します。手動表示の状態は変更しません。

スタイルは「おまかせ／サイバー／ポップ／シンプル」（既存のAuto／Cyber／Pop／Minimal）、強さは「ひかえめ／ふつう／派手」（25／50／85%）です。既存のパターンや詳細値はモード切替では変更しません。詳細設定の別スタイルや数値は「詳細設定の値を使用」と表示し、そのまま使います。

保存済み区間は全て維持し、重ならない検出候補だけを追加します。既存の自動FXを置換する場合だけ再生成を確認し、キャンセルすればデータもON/OFFも変わりません。ロックした自動FXと全ての手動FXは保持します。SRTや音源がない場合は必要な読込操作を案内し、生成しません。音源なしの検出・生成は従来どおり詳細モードから使えます。

「手動で追加」を選び、再生位置を合わせ、アイコン付きの種類を選んで「この再生位置に追加」を押します。初期表示は最長3秒で曲末まで、位置・色・大きさ・強さは既存の既定値です。親機能と手動表示、プレビューをONにし、自動表示の状態は変えず、追加したFXを自動選択します。間奏外でも再生位置を動かさず、その位置に追加したことを案内します。

追加後は「強さ・色・表示時間」の3項目を表示します。プレビューのドラッグで移動、下のFXタイムラインの左右端で長さ変更、一覧選択で削除・複製できます。「詳細編集」「詳細設定を開く」で従来の全設定を開き、「かんたん」で戻れます。同じデータを使い、切替で保存内容・描画結果・Undo履歴を変えません。初期OFFと保存状態も維持します。

## はじめに

統合制作ツールの「間奏演出 / Instrumental FX」を開きます。親機能・Auto・Manualは初期OFF。各スイッチをOFFにしても区間・FX・プリセットを削除しません。プレビューOFFは完成MP4への反映を止めません。親機能OFFはすべての間奏FXを非適用にします。

検出はSRTまたは確定済み歌詞の表示時刻が基準です。音声に歌声がないことを保証する機能ではありません。素材はブラウザ内で処理し、追加サーバーやアカウントは不要です。

## 1. 間奏の自動検出

1. SRTと音源を読み込み、間奏演出をONにします。無音源の場合は「検出用の楽曲全長」を秒で入力します。
2. 「区間を検出・確認」を押します。最小区間は2秒。字幕の重複を結合し、既定で前後0.1秒の表示余白を取ります。
3. 候補を確認し「候補を採用」を押します。区間名・開始・終了・種別・自動生成対象を変更できます。「区間を追加」「再生位置で分割」「次の区間と結合」も利用できます。

フィラー、空文字、間奏マーカーは通常歌詞から除外します。歌詞のない曲は全長をCustom区間にします。歌詞を読み直すと変更候補を提示し、以前の手動区間を保持します。手動区間と重なる候補は採用時に除外されます。全区間の置換は確認付きの別操作です。FXを含む区間を削除しても、そのFXは保持されます。SRT時刻は変更しません。

## 2. 自動エフェクト生成

スタイル（Auto / Cyber / Pop / Cinematic / Rock / Minimal）、パターン（Balanced / Rhythm / Ambient）、強度、シードを選び、「全区間を生成」を押します。読み込み時やONへの切替では演出を生成しません。既存の音量・RMS・Peak・Onset・Beat解析からEnergy / Onset / Beatを再利用します。必要な解析は生成ボタンから実行し、「解析・生成を中止」で取り消せます。曲を再読込すると古い解析の完了結果は採用しません。

生成後にAutoをONにすると表示します。同じ区間・設定・シード・解析結果で同じFXを再現します。0%では自動FXを生成しません。フィラーと重なる場合は密度と透明度を下げます。

## 3. 手動エフェクト追加

再生位置を合わせ、種類を選んで「手動エフェクト追加」を押します。Particle Burst、Light Flash、Geometry Motion、Audio Pulse、Light Trails、Transition Accentに対応します。最長3秒で追加し、親機能・Manual・プレビューをONにします。選択区間の開始位置へ移動せず、現在の再生位置を使います。音源がなくても再生位置と数値時刻で作成できます。

## 4. 個別エフェクト編集

「対象エフェクト」で1つ選択し、開始・終了・表示時間、X/Y、拡大率、回転、不透明度、カラー、ブレンド、速度、強度、ビート、前面／背面、表示、ロックを変更します。固有設定には粒子数・寿命・発光範囲・図形・線幅・回転速度・軌跡長・アクセント種類等があります。

プレビュー直接編集をONにすると、停止中にFX中心付近をクリックして移動、四隅で拡大、上の丸で回転できます。選択枠はプレビュー専用です。同一区間の他のFXは動きません。リストはAuto→Manual、それぞれ下から上の描画順。歌詞の背面／前面と、トラック内順序を変更できます。

追加トラックの下にAuto / Manual FXトラックを表示します。追加トラック拡張がOFFの場合は間奏パネル内に表示します。左右端で開始／終了を変更、内部ドラッグで移動します。ビートスナップは任意ON。重なったクリップはリストで個別選択できます。

Ctrl+Zで変更を戻し、Ctrl+Shift+Z / Ctrl+Yでやり直します。ロック中は移動・削除・再生成を禁止します。複製とプリセットは元の編集から独立します。専用プリセットの保存・適用・名前変更・削除・複製はプロジェクト内に保持します。

## 5. 自動・手動のON/OFF

親機能がONの間、AutoとManualは独立して使えます。両方ONで合成します。ビート設定の親子関係は、自動FXには自動ビート設定と個別設定の両方、手動FXには個別設定が作用します。音源がなくても保存済み解析を再利用できます。解析データがなければ静的／周期的な演出にフォールバックします。

## 6. 再生成

全区間・選択区間・選択Auto FXだけの再生成に対応。ロックしたAuto FXは保持されます。Manual FX、字幕、映像解析結果は変更しません。「生成前へ戻す」は直前のAuto FXを復元し、Undoでも取り消せます。Auto FXを手動へ変換、または複製して独立編集できます。

## 7. 保存・復元

従来のプロジェクトJSON（version 1）の `studio.instrumentalFx` に保存します。スイッチ、区間、FX、パラメータ、順序、シード、解析の小型時系列、プリセット、ロックを保存します。旧JSONは新機能OFFで読み込みます。既存の自動保存、および統合制作ツールのIndexedDB自動保存にも含まれます。音源・動画の本体は従来どおり再指定します。音源未指定でもFXの設定は保持されます。

## 8. MP4書き出し

完成MP4と既存の簡易動画出力は背景・歌詞と間奏FXを合成します。プレビューと書き出しは同じ時刻・固定シードのCanvas処理を使います。書き出し範囲とプレビュー速度に依存して演出内容を変えません。

字幕フロント・二値／グレーマット・透過歌詞PNG連番は従来の字幕専用仕様で、間奏FXを含みません。FXを含むRGB・マットペア、透過FX連番、WebMはv1.0では提供しません。完成MP4を使ってください。

## 9. トラブルと対処

- 表示されない：親機能、Auto／Manual、個別表示、プレビュー表示と対象時刻を確認してください。初期OFFです。
- 検出がずれる：全長、SRT時刻、最小区間、境界余白を確認し、区間を手動修正してください。
- 人物回避が効かない：同じ背景素材の有効な映像解析結果が必要です。間奏機能は映像解析を自動開始しません。未解析・素材不一致・範囲不足では通常配置になり、回避成功とは表示しません。候補評価は推定で、全粒子の軌道を保証しません。
- 生成が多すぎる：Ambientまたは短い対象区間にしてください。Auto・Manual各512件、同一平面の同時描画20件、品質ごとの粒子上限があります。
- 動画が重い：描画品質をlowにし、粒子数を減らしてください。画面外／非表示FXは描画しません。
- 点滅が強い：既定ONのフラッシュ制限を保持してください。間隔・局所範囲・合計の明度を制限し、OSの動きを減らす設定も反映します。刺激を完全に除く保証ではありません。
- 音源を読み直した：生成ボタンから再解析します。キャンセル／別プロジェクトへの切替では旧結果を採用しません。
- ロックしたFXを編集できない：個別ロックを解除してください。
