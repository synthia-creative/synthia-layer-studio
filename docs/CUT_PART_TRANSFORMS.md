# カット・パーツの独立編集

「文字単位編集」をONにして直接編集モードで **カット・パーツ / Cut・Part** を選びます。Groupは字幕の全カット、Cutは時間差のあるひとつのカット、Partは同時表示するひとつの描画ブロックを変形します。Line / Characterは文字の編集です。

## 操作

1. 字幕・対象一覧から選びます。カット番号、文字、描画スロット、識別IDを表示し、該当カットへシークします。時間外、画面外、重なった対象も一覧から選べます。
2. 枠内ドラッグで移動、四隅で拡大縮小、上の丸で回転します。選択中のカット枠内ではそのカットをドラッグします。別対象への切替は一覧が確実です。
3. X/Yは親座標で画面幅・高さに対する移動量%（初期0、−400〜400）、倍率は%（初期100、5〜1000）、回転は度（初期0、−360〜360）。空欄・不正値は採用しません。
4. 位置・倍率・回転だけ、または選択対象の全変形をリセットできます。兄弟パーツ、親Group、文字編集、字幕時刻は変えません。数値確定、リセット、1回のドラッグは既存Undo / Redoの対象です。
5. Group → Cut → Partを組み合わせられます。字幕ロック、再生、Tap、書き出し中の編集は禁止します。編集機能OFFでも保存済み変形は描画します。

## 対応スタイルと所属

| スタイル | 独立パーツ | 同時に変形する描画 |
|---|---|---|
| テープ：積み重ね | 各テープ片 | 文字、テープ台紙、縞、陰影 |
| テープ：単体・交差 | 本テープ、副テープ | 本テープには番号・ローマ字ラベルも付属 |
| ラベル貼り | 各ラベル、中央の円または文字 | 文字とその台紙、中央要素 |
| コマ割り | 各パネル | 文字、輪郭、台紙、内部の集中線・トーン |
| その他 | カット全体 | カットに属する文字・装飾をすべて |

その他のスタイルは内部パーツ分割が未対応と表示します。安全な分割にはそのレイアウト固有の描画スコープの追加が必要です。前面の共通装飾はカット全体に所属し、個別Partへ複製しません。背景・画面装飾・追加レイヤーは子変形に含めません。「中央を空ける」は各帯を別対象（B）として扱い、既存帯クリップを保持します。外接枠は影・パス制御点などを含む保守的な範囲です。画面外の部分は出力で切れます。

再現例：通常歌詞に `夜明けの色を/覚えてる` を入れ、テープに指定します。カット2個なら各フレーズを別々に編集できます。カット1個の積み重ねテープでは「覚えてる」の片だけを編集し、前半の片を固定できます。乱数により積み重ね以外が選ばれた場合はスタイルの細部を変えるか再生成してください。

## 保存・再生成・出力

JSONとIndexedDBに独立したUUIDを保存します。旧JSONは新しい変形を恒等変換として読み込みます。時刻・配色・書体だけの変更は構成署名に含めません。再生成・ガチャで構成が変わり対応を保証できない値は削除せず退避し、件数を通知します。無関係な対象には適用せず、元の構成へ戻すと再適用します。Group値は保持します。通常歌詞の同文行には出現順の限界があるため、厳密な識別には時刻付き字幕を使ってください。

モーションライブラリの汎用レシピにはPart変形を含めません。レシピは別の文章にも適用できるため、Part設定は現在のプロジェクトに保持し、適用後の構成に一致した場合だけ有効にします。

フロント、二値／半透明マット、簡易／完成MP4、透過PNG連番は同じ変形計算を使用し、操作枠を含めません。Safe Zoneは装飾込みの変形後範囲を測定します。解析OFFで解析を開始しません。既存手動位置は文字にデバイス座標で1回だけ加算し、共有装飾の従来位置を維持します。

## 開発契約

`studio.partTransforms[id] = {owner, signature, kind, transform}`。idは`part-UUID`、ownerは安定した字幕ID、kindは`cut`または`part`。署名は全文・カット配列・分割構成・描画スロットを含み、配列番号だけで識別しません。未知レコード・不正数値は正規化します。複製は新しいUUIDでコピー、削除はその字幕のレコードだけを削除します。

`11zzzzzz_parts.js` が計画に対象を付与し、`renderEffectPart` でレイアウトが明示した描画処理を囲みます。文字一致から所属を推測せず、Canvas画像を切り抜きません。静止基準矩形は1pxの測定Canvasで描画命令の幾何から記録し、カット単位のWeakMapにキャッシュします。Groupの基準計測では子変形を除外します。実フレームの範囲は同じ描画命令から記録します。

行列の外側から順に、完成合成Lyrics → Group → 既存カメラ → Cut → Part → 文字アニメーション／Line・Character。背景と画面装飾は子スコープを迂回します。出力解像度に応じて同じ正規化移動量を使います。UIは親行列を逆変換してドラッグ量を求め、専用のプレビューCanvasへ枠を表示します。

検証：`python build.py`、`node dev/part_transform_test.js`、既存の`layer_test.js`、`filler_test.js`、`simple_export_test.js`等、および`dev/tsconfig.studio.json`の型チェック。実ブラウザと実MP4／PNGの検証も必要です。
