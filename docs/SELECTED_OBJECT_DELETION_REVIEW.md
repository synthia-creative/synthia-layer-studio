## 実装範囲

| 選択対象 | 処理 |
| --- | --- |
| 文字／複数文字 | 元のコードポイント番号を維持し、書記素クラスタ全体の描画だけを抑止。詰め直さない |
| 文字効果のみ | アニメーション適用前の文字を再描画。手動変形と本文は保持 |
| 行／演出グループ | 対象字幕の描画スコープを抑止。本文と時刻は保持 |
| カット全体 | 対象カット署名の描画だけを抑止。別カット・コンパニオンは独立 |
| テープ／ラベル／パネル | 既存の明示スロットごとに削除 |
| 個別装飾／文字処理 | カット所有の独立スロットを追加。装飾レジストリごとに選択可能 |
| Instrumental FX | 明示選択したAuto／Manual FXをIDで削除。区間・他FX・字幕は保持 |

Delete / Backspace／ツールバーのゴミ箱を実装。Ctrl+Z、Ctrl+Y、Ctrl+Shift+Zは既存の時系列履歴を使用。一覧でCtrl / Shiftの複数選択ができる。入力欄・SRT欄・IME・表示中ダイアログ・Tap Sync・再生・書き出し・FX生成中は誤削除を防ぐ。ロックを尊重する。削除後は選択とヒット情報をクリアする。20件超の一括削除だけ確認を表示する。

`studio.deletedObjects` は追加のJSONフィールドで、古いJSONは空の削除状態として読み込める。所有者ID、本文、カット／パーツ構成の署名を検証する。書体・配色・時刻の変更では対応を維持し、明示的な本文／構成変更で対応不明になった記録は別オブジェクトへ適用せず保留する。SRT化・複製・明示的な字幕削除でも所有者を追従させる。

文字・パーツを隠してもレイアウト用の境界を保持し、残す装飾の位置が変わることを防ぐ。描画抑止は既存の共通Rendererへ接続し、プレビューだけを消す処理にはしない。

## 制限・未検証

1. 既存の内部パーツ分割はテープ・ラベル・パネルに対応する。他スタイルの任意の内部描画プリミティブを一個ずつ選ぶ機能は未実装。カット全体と各登録装飾は独立して削除できる。全スタイルの任意図形まで含む完全な要件達成とは報告しない。
2. FX内の各粒子・図形はFX一個として扱う。個々の粒子への永続IDは追加していない。
3. 「文字効果のみ」はmainDrawへ適用される入場・保持・退場・文字処理を除去する。レイアウト自体が作る図形・画面カメラ・全体ポスト処理は文字効果から分離していない。
4. 既存仕様どおりInstrumental FXは完成／簡易MP4に含まれ、字幕専用フロント／マット・PNGには含まれない。出力対象を変更していない。
5. 長時間・4K・実曲／実動画素材・音声付き出力と、人による操作の受入れは未検証。短い合成テスト素材による結果。
6. 元フォルダへの反映はユーザーの承認後に実施した。公開は行わない。
